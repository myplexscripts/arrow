About

Arrowflow

Arrowflow is a compact logic game built around one rule: the maze itself is made from intertwined arrows. Each arrow is one continuous path, and its head can leave only when no other active arrow blocks the lane ahead. Pull the free arrows out to untangle the whole shape.

This HTML demo includes generated solvable levels, local progress, coins, hints, haptics, sound, pan and zoom, a shop, and a rewarded ad placeholder.
